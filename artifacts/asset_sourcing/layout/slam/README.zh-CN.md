# 分离式 AMR 取放工位

Gazebo 场景内净尺寸为 7.10 × 5.05 m。取料和货架分设两端，中间固定岛挡住停靠点之间的直达线，外围墙和西北侧柜提供不对称布景。地面蓝线表示主导航参考线，琥珀线表示倒出与低速靠站段。小车在 A 点以静态收拢姿态显示。货架沿用 Fuel 书架的层板几何，在本场景使用灰色金属外观。

[俯视示意图](layout.png) · [Gazebo 窗口截图](gazebo.png) · [SDF](slam_workcell.sdf)

## 路线和停靠

坐标为世界 XY，单位 m，停靠位置指车体中心。

| 位置 | XY | 朝向与用途 |
| --- | --- | --- |
| A 取盘 | (−2.30, −1.20) | 朝 −X，取盘点在 (−2.91, −1.20) |
| A 倒出点 | (−1.45, −1.20) | 车先倒出 0.85，再原地掉头向东 |
| B1 转弯点 | (1.49, −1.20) | 向北转 90°，进入货架侧通道 |
| B1 等待点 | (1.49, 0.55) | 停在等待点，最后沿 +Y 直线靠站 0.96 |
| B1 停靠 | (1.49, 1.51) | 朝 +Y，对应每层第 1～3 槽 |
| B2 停靠 | (1.81, 1.51) | 朝 +Y，对应每层第 3～5 槽，使用 X=1.81 的转弯点和等待点 |

两工位中心相隔约 5.7 m，A 到 B1 的停靠中心直线距离约 4.66 m，绕岛参考路线 **6.50 m**，到 B2 为 6.82 m。B1 和 B2 是同一辆车的分次站位。若从 B1 换到 B2，先退到等待线外再换道。

## 净距与可达范围

- 车体尺寸 700 × 500 mm。收拢显示姿态的机械臂网格投影落在车体包络内。原地转向按半径 430.1 mm 的外包圆检查，规划的两个转向位置离最近障碍至少约 **620 mm**。
- 主通道东向直行时，车体到最近固定障碍至少 **800 mm**。B1 北向通道经过中央岛时，车侧到岛约 **640 mm**。这些数值按理想路线上的车体投影计算。
- A 和 B 的终点，车头到传送带或货架前缘均留 **170 mm**。取盘点至肩轴 310 mm。货架开口在 Y=2.03，盘中心目标仍在 Y=2.21，盘前缘收进开口约 18.7 mm。
- 保留 250 mm 臂底板安装面假设，传送带、货架下层、货架上层支撑面离地分别为 **650 / 570 / 755 mm**。全尺寸盘的名义 TCP 目标仍为 657.35 / 577.35 / 762.35 mm。两处货架停靠覆盖各自槽中心，并以全尺寸盘前缘贴齐开口为起点，对沿槽中心线的 TCP 点位作了平面半径与升降检查，半径范围 58.7–430.8 mm。

Gazebo 中已加载小车、机械臂、两工位和路线标记。路线使用静态示意线。净距核查覆盖固定障碍和车体包络，端点与入槽方向使用现有解析运动学。运行 SLAM、定位误差、实际携盘姿态、机械臂实体干涉和低层插拔仍需分开验证。 [几何核查](geometry-check.txt) · [机械臂高度参数](../../../../prrr_arm_description/README.zh-CN.md)

## 打开场景

在仓库根目录运行，使用项目现有的 Jazzy / Harmonic Conda 环境。

```bash
mkdir -p "$PWD/log/asset_slam_layout/fuel"
bash tools/run_isolated.sh env \
  GZ_PARTITION="ic_tray_slam_layout_$$" ROS_DOMAIN_ID=176 GZ_IP=127.0.0.1 \
  QT_QPA_PLATFORM=xcb \
  GZ_SIM_RESOURCE_PATH="$PWD/artifacts/asset_sourcing/preview/models:$PWD" \
  GZ_FUEL_CACHE_PATH="$PWD/log/asset_slam_layout/fuel" \
  gz sim -v 3 "$PWD/artifacts/asset_sourcing/layout/slam/slam_workcell.sdf"
```
